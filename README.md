# web_project_api_full

Aplicacion de gestion de tareas (task manager) con autenticacion de usuarios, tablero Kanban y vista de lista.

## Stack

- **Frontend:** React + Vite, JavaScript (JSX), CSS puro
- **Backend:** Node.js + Express
- **Base de datos:** MongoDB + Mongoose
- **Autenticacion:** JWT + bcrypt

## Estructura

```
web_project_api_full/
├── backend/     API REST (Express + Mongoose)
└── frontend/    SPA (React + Vite)
```
